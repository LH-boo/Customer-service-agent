# 医院服务制度

## 一、预约取消与退号规则（编号 YY-2026-03）

1. 就诊前可通过公众号、客服电话或窗口取消预约，号源实时释放。
2. 线上取消需至少提前 2 小时办理；距就诊不足 2 小时需联系人工客服或到窗口办理。
3. 已支付挂号费且未就诊的，取消后费用原路退回，通常 1-3 个工作日到账。
4. 专家号取消后不保证可再次预约到同一专家，请谨慎操作。
5. 同一患者 30 天内取消预约超过 5 次，系统将限制线上预约 7 天。

## 二、预约变更与停诊通知制度（编号 YY-2026-04）

1. 因医生临时手术、会诊、培训等原因停诊或调整出诊时间，医院应通过短信、公众号推送等方式提前通知已预约患者。
2. 停诊通知原则上应至少提前 2 小时发送；突发情况无法提前通知的，应在患者到院后由门诊服务中心协调同一专科其他医生接诊或办理改约、退号。
3. 因医院原因导致患者无法就诊的，免收挂号费，已支付费用全额退回，并优先安排改约。
4. 患者对停诊通知不及时提出的意见，由门诊服务中心登记并核实，属于服务流程问题的纳入投诉工单处理。

## 三、投诉与建议处理流程（编号 YY-2026-05）

1. 受理渠道：客服窗口、客服电话 0571-88000000、公众号「投诉建议」、院内意见箱。
2. 受理时限：工作时间内 2 小时内登记，24 小时内首次联系患者。
3. 处理时限：一般投诉 3 个工作日内答复；复杂投诉 7 个工作日内答复并说明进度。
4. 处理流程：登记工单 → 分派责任部门 → 调查核实 → 处理与整改 → 回访患者 → 归档。
5. 涉及医疗质量与安全的投诉，转医务科与质量管理办公室联合处理。
6. 患者对处理结果不满意，可申请复核，或向卫生健康行政部门反映。

## 四、费用与退费说明（编号 YY-2026-06）

1. 门诊费用按项目收取，缴费后可在公众号或收费窗口查询费用明细。
2. 未执行的检查、检验项目可申请退费；已执行项目原则上不予退费。
3. 退费需携带缴费凭证、就诊卡到收费窗口办理，医保结算部分按医保规定退回。
4. 对费用有疑问，可申请费用复核，收费处应在 3 个工作日内出具核对结果。
5. 费用争议金额较大或涉及重复收费的，转财务收费处与医保办联合核查。

## 五、患者隐私保护制度

1. 患者病历、检查报告、费用信息属于个人敏感信息，仅限本人或授权代理人查询。
2. 医院工作人员不得在非工作场景泄露患者信息；违反者按医院制度追责。
3. 线上客服仅能查询当前登录患者本人授权范围内的数据，不提供他人信息查询。
4. 涉及第三方（家属）代查，需提供授权委托书及双方身份证明，到窗口办理。
